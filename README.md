## 🎮 Overview

BodySlide and Outfit Studio allow you to reshape NPC bodies and outfits with sliders, build custom meshes for any body preset, and convert outfits between body types.

Whether you're a newcomer or a veteran, BodySlide and Outfit Studio provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
